# Talk (/chat) UX audit

Tested at 390, 820 (spot), 1440 and 320 (one screen). Screenshots are in /tmp/cad-ux/shots/talk/. Seeded data was changed: I sent about 15 messages, created sessions and kanban/background runs, pinned 'Telegram: grocery list', created one share link, and left the 'ux-test'/'ux-two' profile in place. Pinned and archive were undone except the pin.

Test note: the shared Chromium stalled with many tabs (6-connection-per-host limit). Some of the 'Loading…' times below are partly that. Server load was also high (load avg 6 to 12; /api/status took up to 20 s by curl).

## 1. Flows walked
- Open /chat (phone, desktop) → natural. It opens the agent's newest session. Desktop shows 'Opening default's latest conversation…' while loading.
- Pick agent from crew (phone strip on the empty/new view, rail at 820, sidebar at 1440) → natural. Agent chip in the composer settings also works and says it starts a new chat.
- Switch agent with a draft in the box → awkward. The draft stays with the old session (see #8).
- Session list: Sessions sheet (phone) vs column (820/1440) → natural. Grouping, pinned section, status labels, and 44 px rows are good.
- Session search → awkward on slow servers: 'Searching default…' for 16 s once. Result rows are clear. Empty state is clear.
- Filters, 'All profiles' toggle → natural. The badge ('Filters, 1 on') and 'N sessions across 2 profiles' footer are clear.
- Row actions: pin, archive (with Undo toast), duplicate, rename, export, share → natural. The row ⋮ button is invisible on touch (see #7).
- Open 'Summarise the README' → natural. Tool-call card, markdown list, highlighted code block with Copy (copies, toasts 'Copied').
- New chat, send, reply → natural. URL becomes /chat/<id>?profile=default after the first message.
- Composer intents Ask / Delegate / Repeat → awkward. Delegate works. Repeat has a bug (see #2).
- Attachments (file + image), voice → works. Dictate in headless gives a clear 'microphone is blocked…' message with steps. Hands-free sits under a small chevron.
- Stop a running turn (/hold) → natural. Steer / Queue / Stop sit side by side. Stopped turn shows Continue / Retry. Queued message is paused with 'Run queue'.
- Reload during a running turn → natural. The turn is still shown as Working, and the finished reply appears after /resume.
- Approval in-thread (phone sheet, desktop inline card) → natural. Allow once / session / always / Deny with optional reason. Allow always asks for a passkey (Tier 2) and explains why. 'Allow for this session' and 'Allow once' work.
- Decide-anywhere tray → works. Opening the tray from another session shows other agents' decisions with the same actions. The tray count and Today badge update after an answer.
- Clarify question → natural. Sheet on phone, inline card on desktop. Choices, free text, Skip, countdown.
- Details panel (sheet / right column) → natural. Last command, Work items, About, Plan and run.
- Share link → natural. Duration choice, Tier 1 confirm, link shown once with Copy. See #9 about the share page.
- Slash commands → mostly natural. The list is very long (about 200 entries); /status result renders as a dismissable card. Disabled ones explain why.
- Browser back/forward → awkward. Several history entries per switch; see #5.
- Deep link /chat/<id>?profile=research → works. Without ?profile for a research session → broken-ish (see #3).
- Fork from here → broken in some cases (see #1).
- Edit and resend, Undo last exchange (with 'Put the message back') → natural.

## 3. What works well (do not change)
- Steer / Queue / Stop side by side while a turn runs, with the one-line explanation under the box; paused queue with 'Run queue' after Stop.
- Reload during a turn keeps the Working state and the reply arrives after.
- In-thread approval: command, cwd, rule, four clear choices, optional deny reason ('Sent to the agent… The command does not run'), passkey step-up with a clear explanation and a plain Cancel.
- Clarify card: Recommended choice first, own-words field, countdown, 'If nobody answers, Hermes carries on without one.'
- Sessions sheet/column: groups (Pinned, Today…), source icons, 'Needs you' and 'Draft' badges, Filters badge count, 'All profiles' with the profile name on foreign rows, empty search state, Undo toast on pin/archive.
- Row actions menu text: each item has a plain one-line description, and the disabled worktree item says why.
- Composer 'Send as' menu: each intent has a one-line promise; the chip above the field names a chosen intent and has 'Back to Ask'.
- Details panel (sheet on phone, column on desktop) and the outline column on desktop.
- Share link flow: duration choice → Tier 1 confirm in plain words → link shown once with Copy → pointer to Settings › Security for revoking.
- Edit and resend explains what will be removed ('removes the 3 messages after it (2 replies)'). Undo last exchange offers 'Put the message back'.
- Dictate errors give exact steps; attachments show a size note and per-file remove.
- No horizontal overflow at 320, 390 or 820; desktop 1440 layout (crew, sessions, thread, outline) reads well.
