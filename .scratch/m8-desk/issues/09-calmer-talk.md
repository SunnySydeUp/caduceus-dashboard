# 09: A calmer Talk

**What to build:** Make the Talk screen calm. The owner found it too busy: about 50 controls are on screen before the first word (hand-counted from a screenshot), and Details is always open. The design is the mock `docs/design/mocks/desk/talk-calm.html` (with `talk-calm.css`, `talk-calm.js` and the screenshots `talk-calm-*.png`). Nothing is removed: each control moves one tap away. Owner decisions: sessions stay visible (as a slim titles-only list); build it in three steps.

**Step A: composer.** One field, one context button, one send control.
- The seven setting chips (agent, model, effort, folder, toolsets, prompts, settings) become one quiet line "model, folder" that opens a "This chat" popover with model, effort, folder, toolsets, prompts and Fast mode. An attach button opens attach and saved prompts.
- Ask, Delegate and Repeat become a split Send: Send plus a small menu "Send as". A chip above the field names a non-Ask intent and clears it. The intent rules from ticket 06 are unchanged (per message, resets to Ask, slash commands and attachments refused under Delegate and Repeat).
- The mic shows when the field is empty, and Send when it has text. The waveform (voice conversation) moves into the same voice entry and loses nothing.

**Step B: session rail.** Titles and times only.
- Row = title and time (a state word only when the session needs the owner). Groups Yesterday, This week, Older.
- Filters and maintenance move behind two buttons: **Filters** (Chats and Automation, Failed only, Hide API noise, All profiles, Archived, Source, Project; shows a count when any is on) and **More** (Refresh, Compact view, Select, Import, Claude Code and Codex, Clean up). The stats line becomes a quiet footer. Search stays.
- On a phone the rail is a sheet opened from a header button.

**Step C: header and Details.**
- Details is closed by default and opens by a button (a column from 1280 px, over the thread on a tablet, a sheet on a phone). It shows only sections that have content: Right now, Work and Plan and run are omitted when empty; Last command and About stay.
- The thread's header holds the agent, the session title, Details and a More menu (rename, pin, make this a task, archive). Remove the redundant breadcrumb, terminal button and profile chip from the Talk header (the shell's app bar keeps its search and help; do not change the app bar for other screens).
- Tool and terminal cards in the thread collapse to one line ("3 commands ran, 1 failed") that expands to the existing card.
