# 05: Agent activity: reasoning, tools, subagents, todos

**What to build:** The owner can see what the agent is doing. Streamed reasoning (Hermes's reasoning.delta and thinking.delta events) appears as a collapsible reasoning card. Each tool call is a tool card built from tool.start, tool.generating and tool.complete: name, arguments, output, duration, file diffs and a clear failure state; cards expand like accordions, also in past transcripts. Subagents (subagent.* events) show as subagent cards with their status and a link into their activity.

The desktop context panel gains Todo and Run tabs (a sheet from the app bar on a phone): Todo shows the agent's list from todo.updated, and Run shows subagents and usage. An activity-mode switch picks Worklog, Stream or Final only for the transcript, applied through Hermes's details_mode and tool_progress config plus client rendering.

Each reply shows its token usage and tokens per second from message.complete and session.usage. When the agent saves a memory or a skill, a toast says so; the toast stack also carries general success and error toasts.
